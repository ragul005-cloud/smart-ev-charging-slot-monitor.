
# Smart EV Charging Slot Monitor 🚗⚡

## Project Overview
A single-slot parking occupancy monitoring prototype
developed using Arduino UNO and an IR obstacle sensor.

## Hardware Components
- Arduino UNO
- IR obstacle detection sensor
- USB cable
- Jumper wires

## Working Principle
The IR sensor detects the presence of an object in the
parking slot. Arduino UNO reads the sensor output and
identifies whether the slot is occupied or available.

## Hardware Prototype
The hardware prototype was assembled and connected
to a computer through USB for programming and testing.

## Current Implementation
- Single-slot occupancy detection
- IR sensor interfacing with Arduino UNO

## Future Enhancements
- Red and green LED status indicators
- IoT dashboard for remote monitoring
- Multiple-slot monitoring
- EV charging-status integration

## Applications
- Smart parking demonstrations
- EV charging station monitoring concepts
- Embedded systems and Industrial IoT projects
